Use these shortcuts to work faster in the 3D Viewer.

## Camera

| Shortcut | Action |
|----------|--------|
| **F** | Fit the whole model to the screen |
| **Ctrl + Shift** and drag | Change the focal length |
| **Alt + Shift** and drag | Roll the camera |
| **Mouse wheel** | Zoom in or out |

## First person navigation

| Shortcut | Action |
|----------|--------|
| **Arrow keys** or **W A S D** | Walk forward, left, back, and right |
| **Q** | Go down |
| **E** | Go up |
| **Shift** + direction key | Run |
| **Double click** | Teleport to the selected spot |
| **Left click and drag** | Look around |

## General

| Shortcut | Action |
|----------|--------|
| **Esc** | Exit full screen mode |
